A plugin for Claude Code. Your project gets a board of sprints and stories, and a small team of agents that builds them. Nothing is pushed until it has been reviewed.

1 Customize → Plugins → Add → Add marketplace
2 Enter spatialsparks/bearly-coding
3 Install bearly-coding, then start a new session in the Code tab
$ claude plugin install bearly-coding --marketplace spatialsparks/bearly-coding

Needs git, Node 20 or newer, and TruffleHog. More ways to install

Try the simulator GitHub

Why I built it

I built bearly-coding to help me with my own work. It is the workflow I have coded a variety of different apps with, and it grew with each of them before it became a plugin of its own.

There are great libraries of agent skills already, and Matt Pocock's skills are among the best. They did not fit my style, though. So I kept my own workflow, took the concepts of his that I found most interesting, and worked them into mine.

      Your sessionhands out the sprints
      Sprint leada new one per sprint
      Implementersone per story, own worktree
      Verifieronce per wave
      Two reviewersonce per sprint
      • Works through the board, sprint by sprint, for days if it has to.
      • Doesn't wait for you: questions go into a file and the rest carries on.
      • Pushes a sprint only after both reviewers have read it.

      Everything is a file

      When it needs you

      It writes the question into a file and carries on with whatever doesn't depend on the answer. /resolve walks you through the open ones.

      ⚖️A decisionSomething the story left open.Youpick an option.
      🔑A secretAn API key or a token.Youput it in .env yourself and say "done". It never goes into a file or the chat.
      🛠️Something to set upA cloud project, a paid plan, a failed deploy.Youset it up and say "done".
      👀A lookA story that failed twice.Yougive a hint, build it yourself, or drop it.
      ✅An approvalLanding a sprint, if you asked to approve each one.Yousay yes or no.
      🛑A stopTruffleHog found a secret.Youfix it. Nothing runs until you do.

      Commands

      Two come with the plugin. The rest are copied into your project, where you can edit them.

      Ground rules

      Private

      New repositories are private.

      No secrets in git

      TruffleHog checks every commit and push.

      Reviewed

      Two reviewers read every sprint before it's pushed.

      Runs locally

      Tests and checks run on your machine, not in CI.

      Limited permissions

      Agents only do what the project's settings allow.
