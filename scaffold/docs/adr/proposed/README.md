# Proposed ADRs

A story that makes a decision its file did not fix writes it here, as
`<story-id>-<slug>.md` in the shape of `../_TEMPLATE.md`, with `ADR-NNNN` left as it is. A
planning session does the same, as `<slug>.md`, for a decision an ideation settled.

When the wave is recorded, the sprint lead gives each one the next free number, in the order
of the commits, and moves it to `docs/adr/ADR-NNNN-<slug>.md`. Numbering then, not at writing,
is what keeps two agents in the same wave from both writing `ADR-0014`.

Not every decision belongs here: only one that is hard to reverse, surprising without its
context, and the result of a real trade-off (`docs/PLANNING.md`). Between waves this folder
holds nothing but this file.
